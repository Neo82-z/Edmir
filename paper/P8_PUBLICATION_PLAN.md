## 当前可写的贡献及限制

论文围绕“固定通信条件下，哪些远端访问延迟被隐藏，哪些因计算、资源或同步约束而暴露，以及模型能否选对执行路径”组织。开篇并列串行 staging、流水化 staging 和 direct peer；计数、服务假设、历史排序与实际选择开销分层。

目前已能证明静态计数与归档源码一致，以及在既定历史划分下改进了选择。八卡重新标定后的 19/19 命中可以作为**回顾性开发结果**，不能写成从未查看过的测试集表现；P4→P8 的 3 个失败和 P4 大 N 的失败应一起保留。主表使用完整已测候选，不能采用早期裁剪候选后的更好数字。

我们借鉴 [Ernst 等的工作](https://arxiv.org/abs/2204.14242)将解析指标估计与性能模型、候选选择分开评价。对方在 stencil 等对象上的机制和常数不是我们的依据；本项目的 P² 提交、P−1 远端来源、跨卡依赖、串行 split-K 和 baseline 身份需要自己的证据。

投稿前要回答的核心问题是：**在八卡强基线与同等调优预算下，模型带来的执行方案选择是否仍有可复现、能摊销的收益？** 不能只凭旧弱 host 下的零选择损失声明推理系统优化。

## 下一轮按顺序完成的验证

1. **先锁定八卡执行身份。** 目标为单机 8×A100 SXM4 80GB、全互联 NVLink/P2P。记录真实拓扑矩阵、GPU/驱动/库版本、二进制哈希、计时边界、依赖策略与 metadata 模式。P8 老模型只解释归档 `resource_queues_v1`；修复后的策略另建账本与标定，不用旧参数直接冒充适用。核对非零输入、数值容差、q1 与 serial split-K 的工作量。
2. **补齐 P8 强基线。** 在主对照形状上同时计时逐源 CUTLASS、合并 CUTLASS、合并 cuBLASLt 和原 10 个 fused 候选，统一语义、完整计时和库算法记录。共 13 个实现，不把合并 host 免费加入模型预算。已有公开 fused 实现只有语义、硬件和布局可比时才纳入；否则解释具体不兼容点，不使用异构公开耗时拼接比较。
3. **分开机制诊断与主计时。** 按机制计划先补两点固定粒度流水化及串行控制，再做少量 consumer/依赖诊断；不把合并 host 当作 overlap 基线。 优先检查八卡迁移失败的三个 grouped-N 形状，另检查 M512/q16g2 的绝对误差；在同一台八卡机器选四卡子集，分别控制固定 M 和固定 PM。采集提交/同步、逐设备事件、依赖等待的少量诊断记录；profiler 窗口与无 profiler 稳态计时分开，不能直接相加异步阶段时间。
4. **先冻结，再测新增评价形状。** 标定集、候选预算 k=1/2/3、主表达 ρ=0、ρ=0.25 的敏感性对照和验收门槛都先存档。新增形状优先覆盖 M128–384、未覆盖 K/N 组合、host/fused 双向边界；生成采集包时检查是否已有同执行身份标签。既有三个迁移反例只算诊断集，不能再当独立测试。评价结果不参与这轮系数或特征修订。
5. **验证选择的净收益。** 比较原模型、新模型、训练确定的固定候选、只测两种合并 host、同预算搜索以及完整已测 oracle。主预算为 k=2，k=1/3 同时报出；用于选优的计时区组与用于最终验收的区组分开。记录特征提取、预测、编译、预热与选优成本，并报告在形状复用 R 次时的摊销结果。

原 P8 数字门槛仍保留：方向准确率≥99%、零 host 回退、平均选择损失≤0.5%、最大≤1%。这是既有 top-1 目标，不是本轮临时降低的门槛；有限候选策略需要另报实际 k 个候选的选择成本，不能以理想 top-2 零损失替代 top-1 通过。若强 host 已经吃掉全部收益，就将贡献收敛为边界分析与负结果，不继续宣称 fused 加速。

## 论文修改与投稿顺序

先改方法与实验协议，再填入新证据，最后改摘要和结论。当前 LaTeX 初稿位于相邻仓库 `llm-serving-mlsys-latex/latex/`；其中“强基线完全未测”的表述需改为：P4 已有局部测量且改变了结论，P8 仍缺同批强基线。真实 routed MoE、BF16、在线服务的缺口继续保留。

| 论文内容 | 应交付的证据 |
|---|---|
| 方法与计数 | M/PM、q/g、P4/P8 工作量及独立源码枚举；逻辑字节与硬件事务分开 |
| 预测表达 | 特征定义、非负标定、固定正则化、求解上界、训练/评价身份和不可识别项 |
| 规模与迁移 | P4、P8 分别标定和 P4→P8 分开；固定 M 与固定 PM 两种缩放 |
| 选择质量 | 原模型与新模型、固定基线、强 host、同预算搜索；每形状损失与失败示例 |
| 实用收益 | 新八卡计时、完整选择成本、复用次数与可摊销区间 |
| 可复现材料 | 源码/二进制/环境哈希、原始样本、冻结预测、分析命令与依赖安装记录 |

正文先让合作者审阅问题定义、baseline 身份和证据边界；数据达到上述要求后再形成投稿稿。首投目标为 [Future Generation Computer Systems](https://shop.elsevier.com/journals/future-generation-computer-systems/0167-739X)，以执行代价建模、候选选择与真实应用验证组织论述。JPDC 与 Parallel Computing 保留为后续重新评估时的备选，不并行投稿。正式提交前完成 [FGCS 检查表](FGCS_SUBMISSION_CHECKLIST.md)，并核对学校采用的分区版本；期刊选择不代表接收概率保证。

收尾限定为八卡算子验证与一个真实 MoE 模型的八卡推理实验。完整模型验证已列为必要阶段；新增卡型、多模型/多引擎、量化或其他系统方向不列入本轮。结果支持多大主张就写多大主张，完成后进入成稿。
