## 一句话主问题

> 在固定单机 NVLink 通信条件下，交付与消费远端输入时哪些延迟仍暴露在完成路径上，tile 几何、资源服务和执行依赖如何改变这些延迟；能否据此选择总成本更低的物化或直接读取方案？

当前算子阶段对象是 balanced FP16 代理。八卡模型需显式包含 P 相关工作量、远端来源和执行依赖，并与原论文八卡候选及划分对应；四卡和八卡分别标定，迁移另评。八月旧数据、十月四卡数据和后续修复 runtime 的数据保持独立执行身份。按最新收尾决定，随后必须完成一个模型的八卡真实 BF16 MoE 推理验证，具体边界见[真实 MoE 收尾方案](P8_MOE_CLOSEOUT_PLAN.md)；跨拓扑通用性、多模型和多引擎比较仍不列入本轮。grouped-N 表示输出列 tile 的合并，不等同于专家 Grouped GEMM。host 表示由 host 调度的 GPU 路径，不是 CPU GEMM。

选择属于这条主线的最后一环。通信约定与三种执行路径先于计数和拟合出现；固定粒度流水化 host 补足重叠比较，合并 host 单独检验计算效率。按 NeuSight 思路的具体表示和当前实现边界见 [适配方案](NEUSIGHT_ADAPTATION_PLAN.md)，流水化的两点有界诊断见 [机制计划](P8_MECHANISM_EVIDENCE_PLAN.md)。

## 论证分四层

| 层次 | 本项目可写的内容 | 所需证据与当前缺口 |
|---|---|---|
| 映射和计数 | CTA/grid、K 分片、逻辑 A 重读、串行累加边界、输出读写量 | 源码与独立枚举；属于条件明确的计数，不等于真实事务 |
| 中间机制 | 并发服务、分片深度、实际通信/访存、提交和同步暴露 | 必须独立测量或给出可证伪控制；目前很多量只有代理或上界 |
| 耗时与排序 | 给定执行身份下的标定预测和候选顺序 | 旧完整形状留出仍有九对错误；新冻结预测第一套错 11/100 对，复跑错 10/100 对，二者口径不同 |
| 选择与实用价值 | 有限候选集合是否保留好实现、最终实测选择是否值得 | 强基线、完整候选标签、独立形状、选择开销与重复测量；尚未证实 |

中间指标估对但耗时错，说明组合关系或遗漏机制仍有问题；计数准确不能替代这一检验。少量物理特征加拟合也不能自动称为因果模型。下一处改表达必须对应一个明确反例及可区分的新观测，不继续在旧总耗时上堆参数。

## 主要指标与预算

对形状 x，C_x 是同语义、同环境下实际测得的稳定候选集合。预测只产生有序集合 A_k(x)，k 预先报告为 1、2、3，不在看完测试标签后选取最有利的 k。

\[
r_k(x)=\frac{\min_{c\in A_k(x)}T(x,c)}{\min_{c\in C_x}T(x,c)}-1.
\]

这个量是离线回放中“候选集合内理想选优”的损失。真实运行需要对集合内候选测量并作选择，测量噪声可能产生额外损失。最终部署的选择/验证必须使用分开的测量区组，不能在同批计时上选优再把其最小值当无偏的部署效果。

同时报告原有 top-1 平均/最大选择损失、全部候选对的方向错误、绝对耗时误差、5% 以内候选的保留率、每形状候选数与覆盖缺口。5% 只是本轮预先声明的描述阈值，不替换已经冻结的验收门槛。

候选数缩减不等于时间缩减。未来实测须把校准、特征提取、预测、生成/编译、预热、测量、选择和数值检查分别计费。相对一个预先选定的可部署基线，净收益以

\[
\Delta_R=T_{base}-T_{selected}-\frac{C_{method}-C_{base}}{R}
\]

报告；R 为形状/执行方案的复用次数，C 为相同核算口径的一次性成本。当前没有测得这些完整成本，不能声称减少了多少租机费用。

## 基线和否定条件

必须保留四种身份：原 CUTLASS host、编译器 cuBLAS host、合并 CUTLASS、合并 cuBLASLt。比较需要真实完成依赖、相同输入和数值/计时约定。库算法选择在计时前记录，不把库算法 ID 当连续数值特征。

| 对照 | 回答的问题 | 不能忽略的限制 |
|---|---|---|
| 固定强 materialized host | 是否根本不需要复杂选择器 | 旧数据五个共同覆盖子集中 merged-cuBLASLt 都最优；本轮补充四形状也胜过已测 fused，但新 K768 点由 merged-CUTLASS 胜出 |
| 固定测量两种合并 host 后选优 | 模型 top-2 是否提供额外价值 | 同样计入两种候选的编译和测量成本，选优与验收使用不同区组 |
| 训练阶段确定的固定候选顺序 | 形状特征是否提供额外信息 | 只能使用训练标签，候选覆盖不足必须公开 |
| 等预算均匀随机集合 | 排序是否比随机筛选有效 | 离线算精确期望；不是模型置信度或实测最坏情况 |
| 旧 row_service、当前 regime_max、失败的 residual_depth | 新表达是否真的改进选择 | 所有模型使用同一评价集合，失败版本继续保留 |
| 全部已测合法候选的事后最优 | 当前候选空间有多大可用收益 | 不是可部署免费基线；集合不完整时不能称全空间最优 |

可以预先保留一个强 host 占据候选预算中的一席，但它同样要算编译和测量成本。若强 host 消除了可用收益，论文应转向“融合适用边界与模型失效分析”，不能通过移除强 host 恢复漂亮结果。若简单旧模型取得相同的候选保留效果，新表达没有获得选择价值的证据。

## 执行顺序

1. **已完成本地范围收敛与离线评估。** 读取封存的完整形状留出预测，不重新拟合。见[结果](../experiments/2026-10-25-bounded-candidate-selection/README.md)。旧十形状上三版模型 top-2 都保留已测子集最优，故目前不支持新增模型的必要性。
2. **已完成冻结 GPU 包、完整复跑及附加基线。** 原计划 183 个进程，57 个主配置复跑 171 个进程，读取第一套结果后补充基线 36 个进程，合计 390 个进程。附加阶段单独登记。M256 与大 N 主要错误复现，模型未通过原验收。
3. **已完成受控表达修订及单独的 host 覆盖修订。** [结果](../experiments/2026-10-25-post-gpu-revision/README.md)表明保留较小项有局部改善，但未同时守住旧表现；已有附加 host 标签使 M512 的一项留出误差从 36.28% 降到 6.63%。按[停止条件](POST_GPU_REVISION_PLAN.md)停止新增总耗时拟合项，针对 q/M/g 收集阶段证据。profiler 数据与主计时隔离，不将拟合系数解释为带宽/占用率。
4. **补齐强基线后冻结独立选择评估。** 当前 crossings 多为 fused 对照，不能证明 host/fused 收益。下一阶段在选点、候选、预算、基线和模型全部冻结后测量；同一形状全部候选与重复进程放在同一数据划分中。本轮结果用于修改后归入开发数据，不再宣称独立测试。

当前阶段通过条件是得到正确、可追溯的新观测和能区分假设的比较，**不是**立即宣布选择器通过。冻结 GPU 包的原验收与其 `compiler_admission=false` 保持不变。

## 论文组织建议

1. 明确 balanced All-to-All–GEMM 的执行对象和强基线。
2. 从 q/g 映射推导可检查的计数和资源变化。
3. 给出有边界的成本表达，明确未识别的机制和标定范围。
4. 先检验机制/中间量，再检验耗时和候选保留。
5. 报告强 host、简单策略、旧模型、等预算随机及事后最优，最后计算实际选择成本。
6. 用反例界定适用范围，不将均匀代理结果推广为完整 MoE 或 serving 收益。
