# 短 K 的 split-K 代价：共享分片深度曲线与剩余表达限制

2026-10-28。本轮沿着上一轮的 direct/split-K 剩余错误继续修改。**原四折开发回放的误选由 7/41 降为 5/41，host/fused 方向错误仍为 0；跨 M 泛化没有通过。** 冻结六形状未用于分析或训练，22 个保护文件哈希不变，没有启动 GPU，没有替换默认编译器。

## 源码确认了什么

核对了当前 `runtime/src/nccl_device_fused_cutlass.cu`、`cutlass_sm80_gemm.cuh`，以及执行包固定的 NVIDIA CUTLASS 提交 `dcf215af68a2d08d305076c152a06f201728cd53`。源码哈希见 [verification.json](verification.json)。

- 本路径使用 SM80、FP16 输入/输出、FP32 累加，K tile 为 32，流水线为 3 stages。
- q=1 与 q>1 分别实例化关闭/开启 `SplitKSerial` 的 kernel。**q 增加 K 分片 CTA，不把单次 GEMM 的 CUDA launch 数变成 q 倍。** 因而不能把 q−1 简单解释成额外 kernel 启动次数。
- CUTLASS 的 `gemm/kernel/gemm.h:129` 计算每个 K 分片的主循环长度。当前已验证形状满足 K 能被 32q 整除，故分片深度为 `d=K/(32q)`；一般情况要处理取整，当前模型不能任意推广。
- 同文件 `:303`、`:339`、`:357` 展示 fetch/wait/release 和顺序 epilogue：后续分片读取前一分片的输出，最后一个分片重置 semaphore。每个输出 tile 有 q−1 条分片间顺序依赖。
- `gemm/threadblock/mma_multistage.h:360` 有两级预取 prologue，并按剩余循环屏蔽无效加载。这使“主循环深度是值得单独检查的量”有源码依据；**并不证明 K512 的性能损失就是流水线填充或 semaphore 等待造成的**。

这些是执行结构，不是已测微秒开销。本轮仍拟合完整程序延迟，不将系数冒称为通信、等待或 Tensor Core 独立耗时。当前 runtime 和历史 8/29 采集在外围调度上存在版本差异；这里只借用已核对的 CUTLASS 分片结构，不把新版本端到端耗时套给旧记录。外部测量方法依据承接[上一轮核对记录](../2026-10-28-overlap-evidence/README.md)。

## 实际修改及对照

新代码：`EDM-IR/edmir/compiler/split_stage_selection.py`。上一轮 host 局部曲线保持不变；同候选、同 M/N 的 fused K 残差锚点按新底座重新计算，身份、精度和局部支持规则不变。

原 fused 底座用一个全局 `K/q` 线性项描述分片主循环。新分支将这个项替换为共享的非负分段斜率：

```
d = K/(32q)
r_i(d) = clamp(d−d_i, 0, d_(i+1)−d_i)/128
T_fused = 原有其余代价项 + Σ_i beta_i*r_i(d), beta_i ≥ 0
```

节点仅来自当折训练候选的分片深度，没有针对 K512 或某个错误点手设阈值。q1、q2、q4、grouped-N 等共用系数；原有 CTA、压力和 grouped-N 交互项保留。当前每折 fused 系数从 12 个变为 19 个。等斜率时能恢复原线性深度表达，区间斜率可升可降。超出已观察深度范围会拒绝评分，不做平坦外推。

先保存设计，再执行固定的 2×2 对照：线性/分段深度 × 有/无 `q>1` 路径激活项。另加上一轮原样对照，共 20 次拟合。沿用各训练折的 ridge、capacity、整形状划分和权重，用有 KKT 数值证书的非负最小二乘求解；没有搜索优化器、种子、温度或损失权重。CE/KL 是固定温度下的评价指标，本轮没有把它们加进训练目标。

激活项单独加入没有减少误选；与深度曲线合用时，四折激活系数均为 0，成绩与只用深度曲线相同。因此保留更简单的 `depth` 开发分支，不声称固定 split-K 开销已得到识别。KKT 残差最大约 1.1e−14，只证明给定凸目标求解充分，不证明模型正确。

## 还发现一个可明确证明的表达限制

在 `M64,K512,g=1`、q1/q2 的 CTA 数均不超过当前 capacity=32 时，压力项为 0，group 项为 0。两候选相减后，与 K/output tile 有关的公共项抵消，当前共享底座必然满足：

```
Delta(N) = T(q2)−T(direct)
         = 常数 + 非负系数 × ceil(N/128)
```

所以 Delta 必须随 N 不减。旧观测却为：

| N | 128 | 256 | 512 | 1024 | 2048 |
|---|---:|---:|---:|---:|---:|
| 实测 q2−direct，μs | +8.0 | +3.5 | −2.0 | +1.8 | +1.9 |

仅 N128 与 N512 就构成反例：一个共用参数的单调差值模型，不可能同时预测前者 direct 更快、后者 q2 更快；对这两个**差值标签**，最大绝对差值误差至少是 `(8−(−2))/2=5 μs`。这不是单候选耗时误差下界，也不是四折整体误选率下界：各折参数不同，局部锚点修正也不属于此证明的函数族。

[structural-limit.json](structural-limit.json) 用特征差向量逐折核对了这一非负约束。它表明**现有低并行度表达仍不足**，继续换优化器无法改变该限制。它不证明硬件真实差值一定非单调：历史端到端标签没有提供这些小差值的独立重复置信区间，硬件成因仍需匹配测量。

新曲线已把 N128 的 q2−direct 预测从 −19.52 μs 拉到 −0.63 μs，但实测为 +8.00 μs，仍不能算选对。也不能把 K512 一律改为 direct：M32/N512、M64/N512 的实测确实是 q2 更快。

## 泛化、正确性和执行成本

复用既有三个整组留出，不增加调参划分：

| 全组留出 | 上轮 → 本轮误选 | 本轮平均/最坏选择损失 |
|---|---:|---:|
| 全部 M512 | 2/3 → 2/3 | **7.8102% / 16.0740%** |
| 全部 N2048 | 1/5 → 1/5 | 0.1167% / 0.5835% |
| 全部三个 host 优势点 | 0/3 → 0/3 | 0% / 0% |

这些整组划分的几何支持覆盖均为 0，错误仍照常计分。M512 外推明显未通过，故不提升默认编译器准入状态。

9 项新增测试、12 项条件曲线测试和 9 项原评分器回归测试通过。覆盖：查询标签不进入评分、候选重排/删减不改剩余分数、序列化一致、整形状隔离、FP16/BF16 与实现身份隔离、负系数/损坏 KKT 证书拒绝、深度范围拒绝、原线性底座复现。

本机 20 次拟合不到 1 秒；41 形状/346 候选完整热缓存推理中位数约 14.15 ms、最大 14.48 ms（20 次）。脚本 60 秒预算检查，NNLS 最多 1000 次迭代，候选与节点数量有界。以上是本地回放开销，不是 GPU 算子延迟。
