# 八卡 A100 有界采集

2026-10-25。单机 8×A100 SXM4 80GB、NV12 全互联。用户授权上限 $15 / 1 小时；计划第 45 分钟前停止编译和采集，第 55 分钟前回收并停机。GPU 尚未验证。

8 个历史开发形状，每点 3 个 host（逐源 CUTLASS、合并 CUTLASS、合并 cuBLASLt）与 10 个 fused q/g。fused 主路径明确采用 uniform_immutable_peer_v1；3 个迁移反例各有 4 个旧策略对照，M512 有一个旧 q16g2 对照。共 117 配置、351 次独立进程、101 份编译程序。每进程 20 次预热、100 次计时，全部输入非零、完整 CPU FP32 参考。按形状完成 3 个配对随机区组后再进入下一形状；不凑不完整重复。

本轮验证新 runtime 的正确性和八卡强基线。旧参数与旧执行图不直接适用新策略，本轮不是独立泛化测试，也不包括真实 MoE 或论文最终验收。不把未测候选补成标签。原始计时全部保存，质量异常单列。实际 GPU 库算法、拓扑、源码、二进制、依赖与输入哈希均记录。

运行：python3 run_session.py --deadline <租用开始时间戳加2700> --jobs 12。该 deadline 约束编译与测量子进程；它不会替代平台停机。由本地操作在回收并校验结果后执行平台 Stop，失败或截止时间到时提前停机。

不在服务器下载模型、修改预测器或扩展形状。原生 MoE 接入仍待完成。
