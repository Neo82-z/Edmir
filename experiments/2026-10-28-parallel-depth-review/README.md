# 低并行度、分片深度与 grouped-N 的耦合审查

2026-10-28。完成了结构修改、七轮开发对照、既有整组留出和回归测试。**没有任何分支把原四折总误选降到 5/41 以下，因此未替换此前默认开发模型，也没有升级编译器准入状态。** 冻结六形状未消费，22 个保护文件保持哈希一致，GPU 支出为 0。

本轮有三项可保留的结果：耦合分支改善了 M512 整组留出；M/N 分开的输入规模消除了一个确切的特征重合；成对损失修复了 grouped-N/q8 的局部顺序，却使 host/fused 外推明显退步。最后一项被拒绝，不能只展示它预测准确的那个点。

## 实现和依据

代码在 `EDM-IR/edmir/compiler/parallel_depth_selection.py`，由 `split_stage_selection.py` 显式分发。新入口必须指定变体，不会静默采用实验分支。原 `depth` 分数与上轮逐值相同。

继续使用已固定的 SM80/CUTLASS 串行 split-K 实现：

```
G = ceil(M/64) * ceil(N/(128g))   # 输出 tile / 独立累加链数
B = G*q                          # 分片 CTA 总数
d = K/(32q)                      # 现有整除形状的分片主循环深度
```

q 个分片 CTA 要顺序更新同一个输出 tile，因此 B 和 G 不能混称独立并行度。grouped-N 的 g=2 对应更宽的 CTA 模板，warp 布局、共享内存和复用也不同。[NVIDIA GEMM 指南](https://docs.nvidia.com/deeplearning/performance/dl-performance-matrix-multiplication/index.html)区分了 tile 效率、可用并行度和波次量化，并指出 K 分块需要归约。这支持分别检查这些因素；并不提供本轮经验公式或系数。

本轮保留了以下结构对照，全部使用当前训练折的深度节点、capacity 和 ridge，没有重新搜索它们：

- `depth_parallel`：在旧深度曲线上加入 `u(B)=C/(C+B)` 与深度斜率的乘积，同时有仅加入 u 的对照。C 是此前拟合的压力尺度，不能称作实测 SM 占用率。
- `depth_parallel_group`：上述耦合加上 grouped-N 的分段深度附加项，替换原线性的 `group*K/q`。
- `depth_blend/chain`：将深度代价写成两条非负曲线的凸组合；分别用 B、G 控制混合，允许两种并行度条件下的斜率互换大小。
- `depth_width/width_chain`：宽/窄 CTA 各有深度曲线，取消“宽 CTA 的斜率只能更大”的约束。
- `handoff`：检验 `(q−1)*u(B)*2/(d+2)`。2 来自模板的两级预取 prologue；这个比例是待验证的暴露量假设，不能称为实测等待时间。多数拟合将其系数置零，没有形成选择收益。
- `footprint`：增加两个逻辑输入规模 `2*M*K/q`、`2*N*K/q`，区分 tile 总数相同但 M/N 取向不同的形状。这是每个 K 分片的唯一输入字节数，**不是实际 HBM/NVLink 传输量**。

所有候选继续共享评分规则，不设置特定 shape/q8 例外，不按测试结果翻转分数。模型仍是完整程序延迟的经验预测；计数、代价系数和因果解释分开记录。

同一批 41 个旧开发形状、346 个已测正确候选。包括支持不足的全部形状，未把拒选记为零损失。几何支持覆盖均为 28/41。下表各行是不同模型，不能把各行最好的指标合成一个不存在的模型。

| 分支 | 误选 | 平均选择损失 | 最坏选择损失 | MAPE | host/fused 方向错误 |
|---|---:|---:|---:|---:|---:|
| 上轮 depth | 5/41 | 0.1576% | 2.6316% | 2.7595% | 0 |
| 并行度 × 深度 + grouped-N | 5/41 | 0.1576% | 2.6316% | 2.4947% | 0 |

最低 MAPE 的其他分支也没有减少误选。改善耗时拟合不能替代误选验收。该数据已经多轮开发使用，不能当独立验证集。

## grouped-N/q8：差值正确仍不等于模型可靠

目标是 `[P,M,K,N]=[4,64,8192,1024]`。K 位于这条同 M/N 曲线的高端，没有局部两侧锚点，评分来自跨形状底座。

| 模型 | q4 预测 μs | grouped-N/q8 预测 μs | 后者减前者 μs |
|---|---:|---:|---:|
| 旧 depth | 785.20 | 791.33 | +6.13，错 |
| 耦合 + grouped 深度 | 777.55 | 778.06 | +0.51，仍错 |
| 同结构 + 成对损失 | 706.02 | 701.89 | −4.13，方向正确 |
| 旧实测 | 764.00 | 759.90 | −4.10 |

成对损失确实修正了差值，但两候选都低估约 **58 μs**。共同比例/偏移对同族差分的影响较小，却会损坏相对于独立 host 标定的判断。该分支同时在 `[4,64,512,2048]` 从正确 direct 退回 q2，差值预测由 +3.60 μs 变成 −3.27 μs，而旧实测为 +1.90 μs。

成对目标仅使用当前训练折已测融合候选：相对耗时平方误差，加形状等权的候选差值平方误差。差值归一化分母为 `max(|Ti−Tj|, tau*Tmin)`，tau 沿用原评价温度，两个损失项系数固定为 1。没有按这个目标点选权重，未测候选没有补标签。解仍由带非负约束的凸最小二乘给出；CE/KL 继续只是评价指标。

这次结果说明：不能仅优化同族差分，忽视跨 host/fused 的绝对标定。当前成对分支未被采用。

## 确认并修复了一个特征重合

耦合结构仍主要通过 G 表达 M/N。当 K=4096 时：

| 形状 `[P,M,K,N]` | G | 旧实测 q4−q2 |
|---|---:|---:|
| `[4,64,4096,2048]` | 16 | −3.90 μs |
| `[4,256,4096,512]` | 16 | +6.40 μs |

旧底座对这两个形状的 q4−q2 **特征差向量完全相同**，任意共用系数都只能给出同一个差值。对这些观测，最小可能的最大差值误差至少是 5.15 μs。这个证书只约束底座；同 M/N 的局部锚点校正可能区分两者，也不能据此断言测量无噪声。

新增的 M、N 分开输入规模消除了这对完全重合。13 项新增测试中的一项直接验证旧向量相同、新向量不同。但消除信息丢失不保证训练后的方向正确，run-07 的失败也照常保留。

同样，上轮“低 CTA 区域差值必然随 N 不减”的限制已经被新耦合基打破：测试构造了同时具有正、负分量的差分特征变化，允许系数表达两种方向。结果仍未达标，说明解除一个必要的表达限制，并不足以证明当前拟合、数据覆盖和其余代价项已充分。

## 整组留出的验收

| 整组留出 | 原 depth：误选 / 最坏损失 | 耦合 + grouped：误选 / 最坏损失 | 再加成对损失 |
|---|---:|---:|---:|
| 全部 M512 | 2/3 / 16.074% | **1/3 / 7.357%** | 1/3 / 7.357% |
| 全部 N2048 | 1/5 / 0.584% | 1/5 / 0.584% | **3/5 / 14.001%** |
| 全部 host 优势点 | 0/3 / 0% | 0/3 / 0% | **2/3 / 14.001%** |

这些压力划分的几何支持覆盖均为 0，错误照常计分。仅加输入规模分支在这三项上与原 depth 相同。耦合 + 输入规模的压力成绩与耦合分支相同，但四折多错一个，所以也未合并成默认配置。
