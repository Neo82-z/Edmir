# 预算约束下的本地模拟与评分模型修改

2026-10-28。本轮没有租用、恢复或连接 GPU。冻结六形状只核对文件哈希，没有解析、训练或评分。没有增加优化器训练或搜索；旧模型系数保持不变，所有新预测都使用原训练折已有的观测。目标是降低错误并检验机制，不以旧数据零错误代替独立验证。

开发集仍为 P4 FP16 的 41 个形状、346 个有效候选，原四折整形状留出。全部候选保留，包括适用性检查未通过的 provisional choice；没有增加平局容差、隐藏小损失错误或排除不利样本。

## 修改的表达与失败原因

新模块 [axis_residual_selection.py](../../EDM-IR/edmir/compiler/axis_residual_selection.py) 只读取原模型训练折的锚点，并验证其形状、候选、来源和耗时与已保存模型逐一一致。输入身份、精度和候选实现检查仍由原模型执行。预测不读取查询耗时。

第一轮预先规定两个对照：没有原 K 锚点时，沿同身份、同候选的 M/N 轴插值残差；再测试上界不超过训练最大 M 两倍的 M 外推。更低的 MAPE 没有转化为更少误选，不能据此采用。M/N 插值抹平了短 K 的局部胜负变化，也在 M256 引入 q2/q4 误选。

第二轮是看到第一轮失败后的探索性修改，方案先写入 `round-two-design-before.json`。它取消新 M/N 内插，只保留有界 M 外推：

- host 沿实际 M 对最近两个训练观测的**绝对耗时**作仿射延长，避免“旧 log(M) 底座 + 线性残差”扭曲增长。
- fused 保留原底座的非线性压力，只延长最近两个训练锚点的残差。q/g/精度和其他形状维度必须一致。
- 原 K 插值或 host 区间分支有锚点时优先保留；不替换这些分支。
- 没有专门的 M512、K512 判断或按测试标签切换的阈值。外推总是明确标为未验证，不扩大自动使用范围。

它没有新增拟合系数，但仍然依赖训练标签，是经验性端到端预测，不是已识别的硬件服务时间。外推权重可为负，最近两点误差会被放大；M 工作量增长不保证跨越缓存、调度或通信状态后仍仿射。当前 MAPE 退步与这些限制相容，尚未唯一定位其硬件原因。

## 更细的本地模拟器

[resource_service_simulator.py](../../EDM-IR/edmir/compiler/resource_service_simulator.py) 增加了旧均匀服务模型没有的资源竞争：

1. 分片主循环具有独立计算截止时间，以及显式的内存、链路工作量。
2. 每种资源的活动传输平分该资源带宽；主循环与 epilogue 的内存工作会相互竞争。
3. 同一输出 tile 的 epilogue 保持分片顺序；等待中的 CTA 占驻留槽。
4. 宽模板、尾块、q 造成的写回次数及逻辑输入重放分别计算。A/B 实际交付比例作为明确场景输入，不能把逻辑字节自动当成物理流量。

该实现是**单个源 GEMM 的条件流体模拟**，不是整程序 wall-time 模拟，也不是逐指令 A100 仿真。它未表达实际 SM 放置、缓存行行为、远端源 HBM 竞争和 CPU 提交。每个模拟最多 512 CTA、6B 次事件、4B 次阶段转换，默认 CPU 截止时间 2 秒。事件推进扫描活动 CTA，最坏时间复杂度为 O(B²)，内存 O(B)；不会将此实现称为原先的 O(B log B) 递推。

数值核验覆盖独立恒定服务极限、单槽解析结果、内存服务守恒、共享资源上限、尾块、宽模板、时间单位缩放和遍历上限。高带宽极限与原递推独立比对。

固定 72 组场景共做 **1008 次模拟**，数值单位均为 `synthetic_units`，没有选择“最像旧标签”的参数回填评分器。它能表达“并行度改变→共享服务变慢→q2 优势消失”，不再是所有 CTA 同时入场就完全不受网格影响。

但是，开发集 M64/K512 在 N128/256/512/1024/2048 的实测 q2−direct 符号为 `+,+,−,+,+`；本轮场景只出现 `+,+,+,+,+`、`−,+,+,+,+`、`−,−,−,+,+`，**没有一组解释全部五点**。这是所列场景的失败，不是所有带宽模型不可能解释的证明；单个 GEMM 与整程序观测范围也不同。没有据此宣布测量噪声，更没有制造 GPU 标签。

## 预算与后续边界

本轮不触发任何上机操作。局部验收条件已记录在 `design-before.json`：严格错误减少、完整候选集平均/最坏损失和已有压力切分不退步；“近乎完美”的本地目标更严格要求开发回放与三个压力切分零误选。即使达到，该成绩也只能称为开发结果，不能当作独立硬件验证。

下一处本地问题进一步收敛为：M 外推中尾块比例、CTA 数与流量同时变化时，哪些斜率可转移；以及短 K 的 N 方向非单调性是否需要离散访问/资源映射或程序外围表达。优先沿固定实现和现有记录取证；没有证据时保留竞争解释，不继续通过调参强制把两个点选对。冻结六形状继续留作独立验收，真实 MoE 的预算不在本轮消耗。
