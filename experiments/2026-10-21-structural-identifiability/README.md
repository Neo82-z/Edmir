# M512 / 大 N：结构修正、可识别性与本地验收

**结论：本轮把可在本地检查的计数、结构、求解与稳定性继续推进了一步，但模型仍未通过验收。两个新候选都不替换旧版。下一步需要少量配对测量来区分代价解释，而不是直接开展大规模性能实验。**

没有租用机器、运行 GPU 或引入独立标签。旧模型、默认编译器和已有 GPU 包保持不变。正式状态见 [`verified/decision.json`](verified/decision.json)。

## 1. 修正了什么

新增 [`resource_geometry.py`](../../EDM-IR/edmir/compiler/resource_geometry.py)，对一个源—目的 GEMM 分开记录：

- M、N 两个方向的 tile 数与 A、B 各自的工作集；
- CTA 间缓存复用前的逻辑 A/B 读取量；
- split-K 每分区的 K 深度、额外输出读写、串行 epilogue 边界及 semaphore 槽数。

K 对齐时，各分区覆盖互不重复的 K 区间。因此增加 q 不会把完整 A/B 的逻辑读取量直接乘 q；q 带来的额外 CTA、输出累加和等待必须另计。这些计数由本地枚举测试校验，不是拟合结果。

同时纠正上一轮的一种过强解释：M64/K8192/N2048 与 M256/K8192/N512、q4，确实有相同总网格与不同 N 重读次数，但二者的**总逻辑 A 读取量相同，总逻辑 B 读取量也相同**。不同的是 A/B 工作集和复用方向。不能仅凭耗时不同，就判定多出来的时间一定来自更多网络字节。逻辑读取量也不能无条件当作真实 HBM/互联流量的下界。

新候选把这两个形状映射到不同特征，消除了已知碰撞。工作集的二次响应和网格压力仍是经验基函数，不能解释成已经测出的缓存阈值、带宽或等待时间。

## 2. 两个固定候选都没有过关

本轮先固定两种方案：拆开工作集后按训练内交叉验证选参；以及对相同参数网格的预测取算术平均，检查选参跳变的影响。没有在失败后继续增加特征或针对形状打补丁。

所有外层数据都曾用于开发；以下是回顾性工程检查，不是独立准确率。

| 检查 | 上轮 traffic 候选 | 本轮分开工作集 | 本轮参数平均 |
|---|---:|---:|---:|
| 主检验平均选择损失 | 0.172% | 0.374% | 0.997% |
| 主检验最坏选择损失 | 2.632% | 7.357% | 11.962% |
| M512 主检验与留 K 六次最优选择 | 6/6 | 4/6 | 5/6 |
| 大 N 的 34 次 ±1% 修改后选对 | 32/34 | 34/34 | 0/34 |
| 大 N 的八次额外删组后选对 | 5/8 | 7/8 | 0/8 |
| M512/K4096 的八次额外删组后选对 | 7/8 | 0/8 | 8/8 |

分开工作集的版本在 M512/K4096 上预测 host=1.0516 ms、q2=1.0605 ms；真实值分别是 1.0799 ms、1.0059 ms。host 略被低估，q2 被高估，两者合起来翻转选择。这里没有理由归咎于程序遍历速度或未测得的硬件抖动。

参数平均使 M512 的删组结果稳定，但把大 N 稳定地选错。因此“稳定”必须和“正确”一起验收；平均化不能替代正确的成本结构。±1% 是人为压力测试，不是对 GPU 噪声的估计。

## 3. 旧数据究竟能识别什么

### 跨 M/N 的交互项：有精确的设计缺口

41 个旧形状全部满足 `M=64` 或 `N=512`。令 `m=M/64, n=N/512, k=K/4096`，则在全部旧数据上：

```text
k - k*m - k*n + k*m*n = 0
```

因此 `[k, k*m, k*n, k*m*n]` 四列只有秩 3。独立的计算规模、输入规模和权重规模系数不能通过这组扫描线全部分离。零空间及残差已保存；这里不是数值精度问题。

**这条证明只限制对 M、N 同时变化的推广，不证明当前扫描线上的 M512 / N2048 误选不可能在本地修好。** 当前域限制继续保留，grouped-N 也没有扩展到未测的 M。

### 当前边界：同一训练误差约束允许不同选择

对拆开工作集的固定特征，先只用训练集分别求 host/fused 的最小最大相对误差，再在非负系数和该误差上限内，求各候选能够取得的最大领先幅度。外层真实耗时不进入约束或求解，只在最后报告选择损失。

- 留出 M512 后，host 的最优最大训练误差是 **6.074%**，fused 是 **7.415%**。保持这两个最优上限不变，既能找到 host 获胜的模型，也能找到 q4 获胜的模型；最大领先幅度分别约 **0.0706 ms、0.0493 ms**。并非浮点平局。
- 大 N 在原训练组下，最优误差包络内只找到 host 具有严格优势；但将最大模型误差上限放宽 **1 个百分点**，host、q2、q4 都出现可行获胜模型。
- 留出大 N 后再删除 M256 组，最优误差包络反而只找到错误的 q4 具有严格优势。

完整非负系数、训练误差、预测和 LP 原始/对偶证书在 [`verified/diagnosis.json`](verified/diagnosis.json)。原始 ridge NNLS 另用 BVLS 复算。两种求解器一致，未发现求解错误。

获胜模型要求预测优势超过 `1e-7 ms`，避免将数值平局计入。求解器设有迭代与时间限制；失败会中止审查，不写成“无歧义”。

这里的“同样好”**只指同一最大相对训练误差约束**，不指每条预测完全相同，也不指原 ridge 目标值相同。“放宽 1 个百分点”是模型误差预算，和前面的 ±1% 标签修改是两种不同检查；都不是统计置信区间。

这证明当前模型族和误差预算不能唯一支持边界决策，不证明所有数学模型都已穷尽。继续更换经验函数可能改善旧表格，却不能凭旧表格确认哪种物理解释正确。

## 4. 为什么下一步需要小批新测量

目前同时缺少两个证据：边界附近的新形状，以及能够区分 CPU 提交、设备执行与内存/通信行为的观测。只保留端到端总耗时，无法确定拟合项究竟吸收了哪部分开销。

已生成 [`verified/next_measurements.json`](verified/next_measurements.json)，**只是离线设计，不是可直接执行的任务包**：

- 两个旧锚点：M512/K4096/N512、M64/K4096/N2048，用于核对新环境；
- 五个新形状：K3072 下 M∈{64,192} × N∈{512,1536} 的四点，以及 M512/K3072/N512；
- host、direct、q2、q4、q8 五个候选，三次独立进程块，共 35 个配置、105 次进程运行；顺序已固定并打散。

四点设计既包含同网格的 M64/N1536 与 M192/N512，也包含交叉点 M192/N1536。加入后，上述四列的秩由 3 升到 4。**只有同网格的两个轴上点仍然不够。** 交叉点只用于诊断，不放宽当前预测器的支持范围。

主计时保持无 profiler 的相同 wall-clock 边界。CPU/设备时间线及可用计数器另做诊断，不能把被 profiler 扰动的耗时写回主标签，也不能把重叠阶段直接相加。P4 完整算子需要匹配的四卡环境；单卡 GEMM 不能替代。新环境必须有新身份，不能冒充旧 A100 归档。

这批数据用于模型辨识；一旦用它改模型，就归入开发集，后续仍需另留独立验收数据。没有覆盖 q16/grouped-N，不能宣称已完成全部候选最优性验证。后续可以沿用既有完整验证流程，但本轮没有重新打包或启动它。
