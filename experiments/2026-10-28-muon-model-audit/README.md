# Muon 阅读与评分模型归因审查

2026-10-28。用户确认之前指的是 **Muon**，不是 Dion。上一轮 Dion3 结果保留为另一个优化器的历史对照，不能当作 Muon 的实验结论。本轮阅读两篇原文并核查保存的模型；未启动服务器、未训练新的候选评分器、未使用六个冻结形状。

## 两篇文章实际支持什么

苏剑林的[《从参数对称性到有效学习率》](https://spaces.ac.cn/archives/11985)并不主张无条件接受单参数缩放不变性。文章先指出该假设在许多实际架构中不成立，讨论成对/成组参数的联合缩放，再从重新参数化后的训练轨迹协变性解释有效学习率。实际可借鉴的是检查相对更新量、角度变化和参数化，而不是直接把所有参数投影到固定模长。

对当前模型 `affine(x) + v·tanh(Wx+b)`，缩放 W 通常会改变激活和预测；它也没有文章中 Attention/GLU 的那些联合缩放结构。不能直接假设梯度与参数垂直。应分别记录完整的 `||ΔW||/||W||`、切向更新和实际分数变化，零模长参数需单独处理。当前读出层和 bias 从零初始化，盲目乘以参数模长甚至可能使这些参数无法启动更新。文章的协变性视角仍可用于一般重参数化测试，不依赖我们具有全局缩放对称性。

[《慢即是快：2. Adam的尽头还是Muon？》](https://spaces.ac.cn/archives/11964)研究的是对预条件更新施加正交变换后的优化问题。在其条件下，驻点更新的奇异向量可与梯度的奇异向量联系起来；进一步的奇异值均衡讨论包含启发式猜测，作者明确说明对角预条件情形的局限。它不是“普通 Adam 必然等价于 Muon”或“Muon 在任何网络上一定更好”的定理。

两篇直链在抓取工具返回 403/超时；原站 RSS 只提供摘要。最终通过 Chrome 的原生可访问性正文读完，包括第一篇协变性推导及第二篇对猜测的限制，不以搜索摘要代替全文。

## 首要证据：八卡外推没有被数据约束

现有八卡有效数据是四个形状、20 个候选记录，而不是 60 个独立形状；60 次重复用于合并配置耗时。模型有 40 个输入特征、377 个参数。留出 M256 后：

- 训练只剩三个形状、15 个候选；**q2 记录为零**，有效 fused 记录仅包含 q4 和 q8。
- 同一模型的 AdamW 分支，训练耗时 MAPE 为 **0.0148%**，留出 M256 的候选平均耗时误差为 **24.51%**。
- Dion3 分支分别为 **0.0971%** 和 **29.03%**。这里是耗时 MAPE，不是选择损失；两者均选中了 M256 的实测最快候选。
- 当前模型内已有的仿射分支就能精确拟合这 15 个训练标签：含 bias 的 41 列设计矩阵秩为 15，最大 log-time 拟合误差约 `1.33e-14`。这只证明当前训练记录不要求更大的网络，不能证明实际性能函数线性。

进一步，使用训练集标准化后的设计矩阵 A，构造了参数扰动 δ，满足

\[
A\delta=0,\qquad x_{q2}^{\top}\delta=\log(1.5).
\]

训练分数最大变化只有 `3.05e-16`，但留出 q2 的预测耗时可以乘以 1.5。反向扰动同样成立。该扰动只改变现有仿射参数，不增加任何模型容量；具体向量保存在 results.json，50% 的诊断幅度事先固定，不从留出标签选择。

因此，在现有模型类和观测集合内，存在训练数据无法区分、外推却不同的函数。这叫有限数据下的不可辨识性。权重衰减、初始化和优化器会偏好其中一些解，但这种偏好不构成外推正确的实测证据。它也不是第一篇文章讨论的“所有输入上前向完全等价”的全局参数对称性。

## 损失的目标确实存在冲突，但不是全部原因

令 `s=log(T_hat)`、`p=softmax(-s/τ)`、`r_i=T_i/min(T)-1`。现有期望选择损失满足

\[
\frac{\partial L_{cost}}{\partial s_i}
=\frac{p_i}{\tau}\left(\sum_jp_jr_j-r_i\right).
\]

在 `s=log(T)` 时，耗时 MSE、软目标交叉熵以及当前 best-gap 项的梯度均为零，期望选择损失通常仍不为零。它继续把概率集中到最快候选；best-gap 项只惩罚差距不足，不对称地约束差距过大。因此这个组合优化的分数，不应未经校准就同时解释成真实耗时。

M256 上实测 q2/q8 耗时比为约 **1.0072**。把每个候选分数当作独立变量，对相同损失做局部数值最小化，得到约 **1.0075**；这是标签空间诊断，不是预测器、不是泛化结果，也不声称全局最优。Dion3 留出预测比却约为 **1.706**。所以损失确实鼓励轻微锐化，但这次计算不能支持它独自造成全部误差。当前大幅偏移主要表现为未受约束的外推。

## 四卡 M512 是另一类残留问题

四卡 `[4,512,4096,512]` 的残差确实启用，不能归因于凸包外关闭网络。Dion3+CE 的分解如下（μs）：

| 候选 | 原代价底座 | 加残差后 | 实测 |
|---|---:|---:|---:|
| host | 890.92 | 939.65 | 1079.90 |
| q2 | 1082.79 | 1045.93 | 1005.90 |

底座已经错误偏好 host；残差改善了 host 估计，但没有纠正顺序，导致 **7.3566%** 选择损失。AdamW+CE 同样误选。四卡各折训练耗时 MAPE 约 1.97%–2.99%，并不像八卡训练集那样几乎精确拟合。

这里能确认“底座偏差和残差纠正不足”，尚不能单凭这些结果断言是网络宽度、特定物理特征缺失或优化未充分收敛。需要固定这一折的训练集合，检查 host 代价分项和同预算训练诊断；不能把八卡 q2 未见的结论套到四卡 M512。

## 收敛后的修改顺序

1. **先审查评分含义和支持范围。** 耗时回归与选择分数分别验收，保留实际 regret、耗时误差、CE/KL；不能将带锐化目标的分数无条件指数化后宣称为校准耗时。为未见 q、执行族及精度组合标记外推风险；单纯落在 M/K/N 凸包内不够。
2. **追查四卡 host 底座。** 明确上述 host/q2 差值由哪些已知执行项提供，避免继续仅让通用残差吸收。八卡 q2 的跨形状行为目前缺实测约束，本地可以加物理约束或拒绝无依据的确定性预测，不能宣称已经证明正确。
3. **再做正确的 Muon 对照。** 只对适用矩阵使用 Muon，标量/bias 保留 AdamW；记录有效更新量、角度、分数变化及收敛情况，明确学习率调度。上一轮同为 0.003 并不意味着不同优化器的有效步长相同。保持训练折、架构、数据、损失固定，区分同名义预算与步长对齐的比较，不用冻结六形状调参。

不应凭这两篇文章立刻扩大网络，或认定 Muon 一定能消除当前外推误差。当前证据优先指向 **八卡数据覆盖与可辨识性不足、四卡底座偏差、评分目标混用**；优化器是否带来可重复改进，需要单独验证。
